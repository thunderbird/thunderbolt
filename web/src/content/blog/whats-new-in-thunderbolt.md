Since launching Thunderbolt, we’ve been focused on adding more functionality and features. Here’s what’s changed since launch and what we’re working on next.

## Released

* **Redesign.** Thunderbolt has an updated look and feel.  
* **Skills.** Users can now create and save custom Skills to use throughout their chat with any model or provider. Create a Skill once and reuse it whenever you need it, whether that's turning rough meeting notes into a clean email, or researching a topic and compiling it into a summary you can share.  

  ![Thunderbolt Skills settings showing reusable Ask, Map, Research, Search, and other Skills](/blog/whats-new-in-thunderbolt/skills.webp)

* **Agents.** Connect Thunderbolt to any agent with Agent Client Protocol (ACP) \- including Hermes, OpenClaw, Claude Code, Pi, and more. Here's the [directory of officially supported agents](https://agentclientprotocol.com/get-started/agents) to start from. Many agents that don’t have official ACP support have third-party adapters.  

  ![Thunderbolt Agents settings showing the Agent Client Protocol connection form and Thunderbolt CLI](/blog/whats-new-in-thunderbolt/agents.webp)

* **SAML/SSO.** For enterprise deployments, organizations can configure Thunderbolt to use their internal identity provider. No extra login for people to remember, and a simpler rollout for IT.  
* **Voice mode.** Talk to Thunderbolt instead of typing. Useful when you're on the go, or when you'd rather think out loud.  
* **File upload.** Bring your own files directly into the chat and ask questions about the documents you're already working with.  
* **Search.** Search your past chats instantly.  

  ![Thunderbolt search across chats, models, Skills, agents, and settings](/blog/whats-new-in-thunderbolt/search.webp)

* **Maps, Graphics, Quizzes, and more:** Thunderbolt can now generate UI components directly in chats like maps, quizzes, and custom graphics.

## In progress

* **Agent creation.** Build and configure your own agents directly in Thunderbolt.  
* **Mobile.** Thunderbolt’s mobile experience is coming to app stores soon.  
* **Projects.** Organize your work into folders with shared context.  
* **Thunderbolt CLI.** Use Thunderbolt agent on the command line as a coding agent.

Thunderbolt is open source and self-hostable. You can explore the [docs](https://www.thunderbolt.io/docs), see the full [code on GitHub](https://github.com/thunderbird/thunderbolt), or [contact our team](https://www.thunderbolt.io/) for a demo and custom solutions.
