Office files for the `run_office_script` tests. They come unchanged from the Apache POI test data and are licensed under the Apache License 2.0 (https://www.apache.org/licenses/LICENSE-2.0).

- `testComment.docx`: a Word document with one comment. From https://github.com/apache/poi/tree/trunk/test-data/document.
- `delins.docx`: a Word document with tracked insertions and deletions. From https://github.com/apache/poi/tree/trunk/test-data/document.
- `SampleShow.pptx`: a deck saved by PowerPoint, with slide layouts and notes. From https://github.com/apache/poi/tree/trunk/test-data/slideshow.
- `WithChart.xlsx`: a workbook saved by Excel, with a chart. From https://github.com/apache/poi/tree/trunk/test-data/spreadsheet.
- `WithConditionalFormatting.xlsx`: a workbook saved by Excel, with conditional formatting rules. From the same folder.
- `ExcelPivotTableSample.xlsx`: a workbook saved by Excel, with two pivot tables and a table. From the same folder.
- `WithDrawing.xlsx`: a workbook saved by Excel, with five images. From the same folder.
- `SimpleMacro.xlsm`: a macro-enabled workbook saved by Excel, with a VBA project. From the same folder.
