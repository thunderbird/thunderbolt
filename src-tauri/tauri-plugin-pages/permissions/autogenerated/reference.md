## Default Permission

Manage isolated mobile page surfaces from the trusted main webview.

#### This default permission set includes the following:

- `allow-capabilities`
- `allow-create`
- `allow-present`
- `allow-navigate`
- `allow-action`
- `allow-state`
- `allow-close`
- `allow-snapshot`
- `allow-set-picker`
- `allow-poll-picker`
