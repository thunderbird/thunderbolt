# Licensing by directory

Thunderbolt is a repository containing code with different licensing terms.

- The community code is licensed under the Mozilla Public License 2.0,
  as provided in LICENSE and its source-file notices.
- The admin/ directory is **UNLICENSED, license TBD**, and explicitly excluded
  from the community MPL grant for this version. See admin/LICENSE.
- Third-party code retains its own notices and license terms.

Enterprise support and licensing are available: **info@thunderbolt.io**.

UNLICENSED means no software license is granted for that implementation by
publication; it does not mean public domain or The Unlicense. Shared MPL
components remain MPL when the admin proposal imports them. Previously
published MPL versions retain their existing grants.

The source-header tool selects notices by repository-relative path.
It adds missing notices, checks their scope, and refuses to silently
overwrite a conflicting notice. Moving a file is not permission to relicense it.
